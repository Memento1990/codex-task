# Codex Floatboard v0.14.1

## 修复任务数据库损坏时漏掉可读任务的问题

- 修复任务表前部损坏导致恢复提前中止的问题：顺序读取不完整时，校验任务主键索引后逐项独立读取，跳过不可读记录，保留通过验证的任务，并避免重复恢复。
- 恢复过程增加累计工作量、负载大小与 SQL 超时限制；仍只读取独立证据副本，不直接打开或改写原数据库。
- 修复准备阶段失败时显示具体阶段与安全说明，不再误回到“尚未开始”；保留已有修复、重启和健康确认记录。

## 验证与边界

- 增加首条任务溢出页损坏、中间任务页损坏、非法表结构和既有修复状态保留测试。
- 开发验证包含核心、前端与原生宿主测试，以及 Win32 独立 Desktop 上实际修复、正常退出、辅助进程切换、重启健康确认、后续事件入库和再次启动回归。
- 恢复仅保留可读且通过校验的任务；损坏记录、历史事件和耗时可能无法恢复，不能承诺完整恢复。
- 原数据库与日志继续保留。旧版采集器不具备安全暂停协议时，仍拒绝切换，不强制终止现有 Codex/Reporter 会话。

此版本发布不会自动安装，也不会自动执行数据库修复。
