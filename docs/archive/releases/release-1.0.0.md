# Codex Floatboard v1.0.0

## 全新任务巡检界面

- 采用新版 A 方案：顶部状态统计、紧凑任务矩阵、行内清单/卡点/证据，以及完整详情抽屉。
- 任务按执行中、有卡点、待确认、已完成、未汇报和已取消互斥统计；纯会话占位不进入列表，已同步计划但尚未完整汇报的任务继续保留。
- 支持任务搜索、状态筛选、命令搜索和键盘导航；已完成记录保留独立归档并支持分页和任务定位。
- 新安装默认使用暗色主题和 980×680 主窗，适配 392px 窄窗；保留已有用户的主题、窗口位置和尺寸。

## 设置与工具窗口

- 设置改为即时保存，失败恢复已确认的值并提示原因；多个窗口和后台刷新共享最新设置，字段修改不会重置其他选项。
- 头像球摘要支持悬停显示、固定显示和隐藏；普通桌面通知停留时间支持 1–60 秒，卡点通知继续保留到手动关闭或查看。
- 接入、通知、更新、数据迁移及修复工具沿用真实后端流程，以新版界面集中呈现；必要的诊断和扩展配置在详情中展开。
- 保留系统最小化、独立头像收起按钮、关闭到托盘和不抢焦点的任务通知。

## 真实数据与记录边界

- 证据显示首次汇报时间和稳定标识；同一任务中重复汇报保留首次记录，新任务 episode 单独标识。缺少可追溯记录时保持未知，不使用更新时间替代。
- JSON 归档启用浮点数精确往返解析，保留首次汇报时间在归档和重载前后的精确一致性。
- 待确认时长使用当前等待段的开始记录；步骤和卡点耗时继续使用累计计时，保留“部分记录”和起点未知的含义。
- 证据通过系统默认应用打开受支持的真实文件或网页，失败时提示并保留复制入口。
- 任务仍由 Agent 汇报驱动；界面提供查看、复制和定位，不将原型中的人工推进、解除卡点或 Mock 成功结果带入正式任务。
- 不恢复聊天或工具动态历史，不读取原始对话和工具参数。旧数据、完成归档、接入配置及现有会话继续保留。
