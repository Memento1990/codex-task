# v0.14.0 — 一键修复并重启

## 新增

- 设置中的「修复并重启」只需一次确认，内部自动抢救可读取任务、校验恢复数据库、正常退出看板、安全切换数据目录并重新启动；无需手动操作数据库或运行 BAT。
- 重启后核对新数据目录、实际任务读取和采集器健康，只有通过检查才显示完成。无法恢复任务时不会用空库冒充成功。
- 原数据库及日志保留。恢复后的任务不伪造历史记录、耗时或实时运行状态；部分历史信息可能无法找回。

## 安全与可靠性

- 独立执行器核对看板进程身份并等待正常退出；收集器通过身份、心跳、锁和暂停确认协同切换。
- 不支持安全暂停的旧版收集器会阻止切换，并重新打开原看板；不会强杀 Codex 或正在进行的会话。
- 保留原入口路由，切换后迟到的旧入口上报仍可写入新数据库。
- 恢复任务不会触发历史通知群发；不确定的既有投递不会自动重发。
- 数据已切换但启动验证失败时不回滚新库，可正常重新打开看板继续验证。更新与修复互斥，避免并发重启。

## 验证说明

- 前端 40 项、核心 155 项、原生 6 项测试通过，构建检查通过。
- 独立 Win32 Desktop 原生回归覆盖真实设置确认、自动重启、损坏库任务恢复、后续旧入口上报持久化及再次启动；另覆盖模拟旧采集器阻止切换。
- 截图已留存，但当前测试环境无法完成图像视觉审阅；未覆盖真实输入焦点、托盘、拖拽和多显示器操作。旧采集器阻断测试使用模拟协议缺失的收集器，并非真实历史二进制。

发布不会自动安装或修复正式数据，安装和「修复并重启」仍需用户分别确认。
