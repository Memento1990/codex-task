# Codex Floatboard 1.0.1

恢复方案 A 原版的暗色、卡片分区、开关、完成记录和头像球结构，放大正文与辅助字号。顶部恢复独立置顶和明暗切换；更多按钮打开操作菜单，搜索统一为一个全局入口，可查任务、步骤、卡点、项目与命令。旧版主题首次迁移为暗色，之后保留用户主动选择，窗口大小和位置保留。

数据库修复现在优先复制并验证完整数据库，保留事件、耗时和完成历史。只能部分抢救时，保留副本并停止，不自动切换。失败提示保留本次实际原因，不再被旧的修复记录掩盖。

增加 Windows 文件身份保护：历史采集进程持有已被替换的主库或锁、仍共享日志时，拒绝打开或切换数据库；后续进程持有的身份文件也禁止被替换。采集器必须真正就绪才算启动成功，底层失败记录脱敏的阶段、SQLite 错误码或 Windows 错误码。

修复 Windows 瞬时占用导致修复暂停确认文件更新失败的问题，仅对共享/权限瞬时冲突作有时限的重试。

Hook/MCP 不再因等待采集器启动而超过响应期限，后台检查隔离协议管道，及时返回会话绑定与接收结果；界面仍须确认采集器真实就绪。

本版本不重置任务数据，也不强行结束 Codex 或历史上报进程。若提示旧版采集器无法安全交接或文件身份冲突，请保存工作后正常重启 Windows，再打开看板；旧版 0.7 采集器没有安全退出协议，单独升级界面不能解除其驻留。

发布不包含自动安装。安装版是否恢复，须以升级后实际任务读取、采集心跳和后续汇报验证为准。
