# 变更记录

## 0.7.0 — 2026-10-30

- 切换 C 卡点调度台，提供全部 / 有卡点 / 执行中筛选，宽窗左右分栏、窄窗上下排列。
- 窗口可缩放，默认 772 × 570、最小 392 × 570；保存大小与位置，最小化不覆盖尺寸，全部完成不再自动缩小。
- 显示层迁移为 Tauri 2 + Svelte；采集、SQLite、Hook / MCP、接入与设置统一由 Rust 实现，正式包仅包含两个 EXE。
- 保留原任务、会话绑定、耗时、完成二级窗口、双主题、托盘、自启与叠放通知；通知不抢焦点。
- 本机 GUI、采集器及本工具拥有的 Codex 配置已更新；现存旧 MCP 会话继续兼容，旧产物保留供平滑过渡与回退。
- Rust 26 项、前端模型 3 项、真实 Windows WebView2 交互 35 项检查通过；公开发行说明见 [v0.7.0](v0.7.0.md)，验证摘要见 [发行验证](v0.7.0-validation.md)。

## 0.6.0 — 2026-10-30

- 已完成任务和清单改为二级窗口查看，替换原位展开；主窗仅保留紧凑数量入口。
- 已完成任务入口固定在任务区底部，长列表滚动时仍可使用；全部完成后主窗自动收为摘要。
- 二级窗口复用同一实例，保留备注、耗时、卡点、证据和动态；刷新保留浏览位置，不改变主窗选择。
- 点击完成通知直接定位二级详情，任务重新执行时退出完成列表。

## 0.5.0 — 2026-10-30

- 新增简单设置：开机自启、任务栏显示、黑白主题、消息通知及停留秒数；保存即生效。
- 任务栏默认不显示，保留托盘；自启默认关闭，仅管理本工具当前用户项。
- 消息在右下角向上叠放，默认 3 秒，支持手动关闭、悬停暂停和点击定位。
- 按任务合并新增 / 状态变更，启动静默、不重复播放历史，最多同时显示 4 条。

## 0.4.0 — 2026-10-30

- 完成记录自动归组，重新执行回到可见区域；全部完成时显示完成汇总。

## 0.3.0 — 2026-10-30

- 任务、清单项和卡点增加易读耗时，实时更新，完成 / 解除后冻结，恢复后累计。
