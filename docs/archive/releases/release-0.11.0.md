# v0.11.0 — 消息通知中心

## 新功能

- 新增消息通知中心：集中管理渠道、事件订阅与发送记录，入口为「更多操作 → 消息通知」或设置中的「配置消息通知」。
- 支持企微群机器人 Webhook、飞书群机器人 Webhook、关键词与飞书签名密钥。
- 支持卡点出现、任务完成、卡点解除，外部通知与桌面浮窗独立。
- 增加持久化后台队列、失败重试、过期处理、发送记录与手动重试。
- 凭据由 Windows 当前用户 DPAPI 保护，页面不回显 Webhook 或密钥，只接受官方平台 HTTPS 地址。

## 体验改进

- 补充正在进行的任务接入指引，不会虚构历史进度。
- 界面版本号与打包版本保持一致，改善更新状态展示。

## 使用前须知

- 外部通知默认关闭，首次启用及恢复时不补发历史事件。
- 个人微信机器人暂不可用：尚未确定可验证的扫码接入方案，不提供模拟二维码或虚假在线状态。
- 配置中的发送测试会真实向接收群发消息，请确认群成员和任务标题内容适合对外发送。
- 平台受理不等于已读；网络超时及手动重试可能造成重复。
- 企微/飞书发送代码已实现；发布前采用 fake transport、签名向量及原生配置交互验收，未向真实群发送。真实平台端到端验收仍需专用测试机器人。

## 更新

本次提供便携包、自动更新专用包、签名清单与 SHA256 校验文件。已有 v0.9.0 或更新版本可在「检查更新」中下载，并明确确认后安装。更新不停止 Codex 或 Reporter，不清理正在使用的历史版本。
