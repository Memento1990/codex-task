# Codex Floatboard v0.14.2

## 修复数据库恢复流程

- 修复“修复并重启”在恢复副本可读时仍因任务数量不一致而失败的问题：恢复记录总数与看板可见任务数分别统计，未上报的占位记录继续保留，不再影响准备、应用与启动验证的数量检查。
- 修复结果现在保留具体失败阶段与原因，不再仅提示“修复准备未完成”。
- 遇到无法确认安全暂停的旧版采集器时，明确提示先保存工作，必要时重启 Windows 后再重试；不会强行结束 Codex 或上报进程，也不会绕过安全暂停检查。

## 数据保护边界

- 仍先恢复并校验副本，再在安全暂停、源文件保护和最终校验均通过后切换；原数据库及日志继续保留。
- 无可显示任务时拒绝启用空看板。恢复属于尽力而为，已损坏的任务、历史记录及耗时不保证能够找回。
- 本版本不会自动运行修复、替换数据库或结束旧会话。更新安装仍需用户确认。

## 验证

- 新增“可见任务 + 未上报占位记录”混合恢复、仅占位记录拒绝切换、失败原因保留及历史修复状态不覆盖回归。
- 前端、Rust 核心、原生宿主测试及构建检查通过。
- Win32 独立 Desktop 原生回归覆盖实际设置按钮、修复执行器、正常退出与重启、启动确认、后续上报持久化，以及旧采集器不支持安全暂停时的拒绝切换和原因提示。
