# Codex Floatboard v0.12.0

## 独立功能窗口

- 设置、Codex 接入、版本更新与消息通知改为独立原生置顶窗口；再次打开复用现有窗口。
- 按功能设置初始尺寸并限制在屏幕工作区内，内容独立滚动，不改变主看板尺寸。
- 增加忙碌操作关闭保护与按窗口命令权限；仅主窗口消费任务浮窗通知。

## 诊断与隔离修复

- 区分任务数据库不可读、采集器心跳异常、数据服务异常与浮窗通知失败，避免将数据库错误统称为“采集离线”。
- 数据读取失败时保留最近一次成功任务快照；明确提示不可读不代表已清空，不自动重建或删除数据库/WAL。
- 采集器启动失败保留诊断原因。
- 同一 Codex 配置目录的正式版与 DEV 接入操作增加共享配置锁，降低并发覆盖风险。旧版本不遵守新增锁，不建议同时执行接入修改。

## 开发验证功能

- 新增仅在隔离 DEV 中开放的微信连接验证页（扫码、严格绑定、明确确认后的文本测试及离线恢复）。正式版不开放个人微信通道；不自动发送任务事件，不依赖或安装 OpenClaw。

## 更新与数据安全说明

- 本版本不会自动修复已经损坏的数据库，也不包含任何用户数据或恢复副本。
- 遇到数据库损坏应保留原数据库及 WAL，并独立备份分析；不要删除数据或反复重新接入。恢复副本接管需单独规划，不应热替换运行中数据库。
- 本次排查没有证据确认数据库损坏由更新或 DEV 引起。
- 已签名的自动更新仍需用户明确确认安装；不会强制停止 Codex 或旧 Reporter，会话结束前应保留旧版本目录。

## 验证

- 前端回归、Reporter 核心测试、原生窗口策略测试与 Windows release 构建。
- 隔离 DEV 原生窗口冒烟：独立打开、单例复用、忙碌关闭保护、权限拒绝、无横向溢出、主窗口几何尺寸不变。
- 不声称覆盖所有多显示器/DPI 布局；不声称完成企业微信/飞书真实平台端到端验收或长期微信推送可靠性测试。
