# 贴边头像进度球（DEV）

采用用户确认的方案 1：终端领航员头像、步骤进度环与完成步骤计数。设置中的「头像球任务摘要」支持固定显示、鼠标移到头像上显示、不显示三种模式，默认悬停显示。旧设置开启迁移为悬停显示，关闭迁移为不显示；新模式优先，读取迁移不主动改写旧设置文件。

## 两层收起

- 「折叠详情」只隐藏右侧详情，保留任务进度列表；再次点击展开。详情页签和滚动位置应保留，选择状态写入窗口配置。
- 从标题栏拖动窗口至工作区左/右边缘，松手后收成约 64 逻辑像素的头像球。边缘触发必须来自明确拖动，不由启动、普通布局或程序移窗触发。多屏接缝不作为桌面外缘。
- 点击头像、托盘显示、托盘设置或查看卡点通知均还原面板。还原使用收起前的面板位置、尺寸与状态，不把悬浮球尺寸写成正常窗口尺寸。
- 球体完整露出。悬停摘要不抢焦点、不自动展开任务面板。拖动中不以动画打断操作。
- 点击球体展开后即使仍在边距内也不会再次自动收起，只有主动拖动面板后才重新判断收起。
- 头像球也可拖动：离开原贴边触发范围立即展开并跟随拖动，松手后保持展开；在范围内松手仍保持头像球并保留新的垂直位置。拖动不等同点击恢复，也不把球体尺寸覆盖正常面板尺寸。
- 不方便拖动时，可用顶部工具栏「收起为头像球」图标；更多菜单不再重复此项，图标提供可访问名称与键盘操作。球体支持 Enter / Space 恢复；悬停模式下 Escape 关闭摘要，固定显示模式不因移开鼠标消失。

## 窗口与提醒交互

- 标题栏仅在主指针按住并移动达到 4 逻辑像素后开始拖动；普通单击不触发原生拖动。排队命令执行时再次检查鼠标仍按下，避免快速点击释放后进入原生拖动循环。
- 更多菜单在点击外部、焦点移到菜单外、窗口失焦或按 Escape 时关闭；菜单内部点击照常执行。
- 卡点通知以琥珀色提醒边框、背景与警告图形配合「卡点提醒 · 需要关注」文字区分，普通消息保留中性样式；常驻与手动关闭规则不变。
- 已完成记录是主窗口所属的独立顶层窗口，始终处于其所属主窗口之前，并与主窗口同步置顶层级（取消主窗口置顶时同步取消）；重复打开会恢复最小化并聚焦。

## 进度含义

步骤数只代表结构化计划的完成项，不代表工作量、剩余时间或模型实时在线。无计划显示「—」，不编造百分比；当前任务以选中进行中任务为优先。其他任务有卡点时也显示关注标记。只有真实 completed 状态才表达业务完成，运行停止不视作完成。

## 范围与安全

托盘唤回与贴边窗口操作统一在 UI 线程取得贴边状态锁后执行，避免异步命令持锁等待窗口查询、托盘回调又等待同一锁的死锁。窗口事件保存仍使用非阻塞锁检查。
