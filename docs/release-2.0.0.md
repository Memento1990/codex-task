# Codex Floatboard 2.0.0

任务数据库和后台生命周期改为单 Agent 管理。多个 Codex 会话共用一个后台，默认连接不再创建 Bridge/Reporter；看板关闭后仍继续采集和发送已启用的通知。

- Agent 独占 SQLite，统一用户/profile 身份、受管目录和文件身份校验。存储故障明确报错，不用空列表或新空库掩盖失败。
- 进度事件、任务投影、完成档案、计时依据、通知 outbox 和回执同事务提交，提交成功才返回 accepted；重复修订可幂等重试，内容冲突明确拒绝。
- Codex 使用 loopback HTTP MCP、本地 OAuth 和 PKCE。令牌绑定 profile，支持刷新、撤销；Hook 是有限时的短命客户端。
- 后台由当前用户计划任务托管；正常停止保留当前登录的停止意图，异常退出由同一任务恢复。看板是否随登录打开单独设置。
- 有变更时每日一致性备份，保留最近 14 份；手动、升级前和历史备份保留。提供诊断和独立离线迁移/恢复，恢复只写新目标。
- 删除旧修复窗口、运行中抢救、切库重启、在线搬库、inbox 和旧 stdio 运行链。旧发布与事故证据归档。
- 保留 A 原型的顶部统计、44px 任务行、行内详情、抽屉、头像球、明暗主题。缺失时间保持未知，有证据缺口的耗时保持 partial；断连保留最近快照。

**1.x 必须使用专用迁移安装，不能普通覆盖升级。** 正式数据根改为 `%USERPROFILE%\.codex-floatboard\profiles\<UUID>`。迁移先核对全部历史和两侧增量，冲突逐项确认，新库保持暂停，实际 GUI、数据库与 OAuth 验证后才开放写入。签名包内提供 `migration-install.ps1` 和 `MIGRATION.md`；步骤见 [迁移手册](migration-install.md)。

本地候选已覆盖事务/故障注入、1/10/100 会话、100 轮连接释放、实际 Desktop Codex OAuth、历史副本、签名迁移入口和 Win32 独立 Desktop。执行细节、首次失败与覆盖边界见 [验收报告](../artifacts/agent-runtime-20261109/acceptance.md)。正式数据、安装与现有会话尚未切换；隔离通过不表示旧现场已经恢复。

真实登录、系统焦点/托盘输入、拖动/跨屏及真实外部通知送达不在本轮隔离验收内。磁盘损坏、空间或权限异常仍需要备份和完整性检查。
