# 消息通知（方案 A）

## 功能边界

外部消息通知与桌面消息浮窗独立。在主窗命令搜索中选择「消息通知」，或从「看板设置 → 工具 → 消息通知」进入。外部通知默认关闭；开启后先建立当前任务基线，仅投递后续新事件，不补发历史。

- 企微群机器人：配置群机器人的 HTTPS Webhook，可附加群安全关键词。
- 飞书群机器人：配置 HTTPS Webhook，可选配置签名密钥与安全关键词。
- 个人微信：支持扫码连接、平台要求时的手机验证码，以及从扫码账号发送绑定码确认收件人。完成绑定后还须开启外部通知总开关和微信渠道；已启用连接可在重启后恢复，会话失效时需恢复或重新扫码。它使用独立微信连接，不是企微 Webhook 的别名；绑定状态不代表永久在线或保证送达。

总开关、渠道开关和事件订阅修改后即时保存；Webhook 配置仍须显式保存并确认，取消编辑只放弃尚未保存的输入。关闭窗口不会回滚已保存配置。消息被平台受理不代表收件人已读；渠道测试会真实发送一条消息，Webhook 须先保存、微信须先绑定，并开启总开关及对应渠道。不要把真实凭据、登录二维码或绑定码写入 fixture、测试脚本、截图或问题报告。

## 事件

默认订阅「卡点出现」「任务完成」，默认不订阅「卡点解除」。任务完成仅识别任务状态转入 `completed`，`runtime=idle` 只是本轮结束。卡点通过稳定卡点 ID 识别；明确从 open 转为 closed 才视作解除，缺失不能推断解除。归档记录不触发通知。

通知不附加本地完整路径、会话 ID、命令、代码或原始日志。任务标题、卡点标题由用户/模型提供，本身可能含敏感内容，开启前应确认群成员及标题内容。

## 运行限制

投递在本地后台执行，不依赖配置页持续打开，不阻塞任务快照或桌面浮窗。进程退出、计算机休眠或断网期间不保证送达；没有云端常驻服务。结果未知时不自动或手动重发该记录，无法承诺平台侧 exactly-once。只有明确失败可按规则重试。

Webhook 明确暂时失败最多尝试 3 次，暂时性失败按 5 秒、30 秒退避；所有渠道发送结果未知或发送中断后不会自动重发，也不提供该条记录的手动重试，须先到手机确认。30 分钟未完成的待发消息过期，记录保留 7 天、最多 500 条。清空记录只删除已结束记录，待发记录保留；允许手动重试的失败记录会创建新记录并保留原记录。关闭总开关会跳过待发记录，不能撤回已到达平台或已经发起的请求。发送前在同一存储执行器持久化认领；重启检测到未确认发送则保留 unknown。关闭 GUI 后 Agent 继续投递，历史导入不生成通知。已有 Webhook、key 或签名密钥不回显，空凭据输入表示保留已有凭据；更换凭据需显式保存，删除渠道或断开并删除微信凭据需确认。

## 安全及开发验证

凭据使用 Windows 当前用户 DPAPI 保护；这不是抵御同一用户恶意代码的安全边界。只允许规定平台的 HTTPS Webhook，不允许任意 URL 或重定向。错误结果不得包含请求 URL、key、签名密钥或服务返回的任意原始内容。

开发只使用临时测试目录和 `dev-isolated.ps1 -CodexMode isolated` 启动的隔离 DEV。自动化不得向真实群或真实个人账号发送消息。真实投递验收必须由用户提供专用测试机器人并明确确认；当前实现不代表真实平台端到端验收已完成。

平台参考文档：[企微消息推送配置](https://developer.work.weixin.qq.com/document/path/91770)、[飞书自定义机器人](https://open.feishu.cn/document/client-docs/bot-v3/add-custom-bot)。这些站点动态呈现正文；上线前仍需按当时平台限制核验账户、限流、安全关键词、签名和 IP 白名单配置。
