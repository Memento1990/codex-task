# Codex Task v0.7.0 · 卡点调度台

GitHub 首次公开发布，日期：2026-10-31。产品运行版本保持 0.7.0，本次整理源码、MIT 许可证、产品文档及已验证的 Windows 便携包，没有替换本机运行程序或修改正式 Codex 接入配置。

## 本版亮点

- **多任务卡点视图**：全部 / 有卡点 / 执行中筛选，集中查看进度、原因、影响、处理方和解除条件。
- **自适应浮窗**：默认 772 × 570、最小 392 × 570，保存大小与位置；宽窗左右分栏、窄窗上下排列。
- **Rust + Tauri + Svelte**：GUI 和 Reporter 两个 EXE 运行，不再依赖 Python、Qt 或 Node。
- **日常视图**：任务清单、耗时、证据、动态、完成记录、双主题、托盘和不抢焦点通知。
- **本地接入**：Hook / MCP 预检、配置备份、差异预览及按条目撤销，保留旧会话兼容。

## 下载与启动

下载 `CodexFloatboard-0.7.0-windows-x64.zip`，完整解压，运行 `CodexFloatboard/CodexFloatboard.exe`。保留同目录 `FloatboardReporter.exe`。

- 平台：Windows x64。
- 系统前置：WebView2 Runtime、Visual C++ x64 运行库。
- 附件：便携 ZIP、`SHA256SUMS.txt`。GitHub 自动提供的 Source code 归档仅含源码，不含 EXE。
- 包含：两个 EXE、离线快速说明、MIT 许可证及第三方依赖许可文本。
- 程序未签名，无安装器；使用 `Get-FileHash -Algorithm SHA256` 核对 ZIP 校验和。

## 升级与回退

已有 0.6.0 用户先备份本机数据和接入配置，将新版解压到独立目录。沿用 `%LOCALAPPDATA%\CodexFloatboard\data`，在新版接入窗口核对配置。旧会话可能仍依赖旧 Reporter，结束前不要删除其目录。

回退时退出新版 GUI，运行保留的兼容旧版。保留任务库；接入回退按条目处理，不用整份旧配置覆盖后续改动。首次使用的用户按 README 连接 Codex，并启动会加载新配置的新会话。

## 已知边界

- 尚不支持自动派发、审批、解除卡点或恢复会话。
- 会话定位使用复制 ID，未提供已验证的桌面深链。
- WSL Linux CLI、macOS、Linux 和真实子 Agent 路由尚未实际验收。
- 耗时包含等待和受阻，表示自然经过时间；缺失起点的历史明确标识。
- 本版不依赖 Python / Qt；旧实现已在后续仓库清理中移除，可从 Git 历史查阅。
