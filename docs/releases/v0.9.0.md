# v0.9.0 — GitHub Release 检查与安全自动更新

2026-11-02发布。已完成生产公钥构建、生产签名包、原生更新入口检查，以及独立两版fixture成功升级19项、篡改拒绝34项和故障恢复23项断言。Rust测试75项、前端模型测试10项通过。完整范围与网络复验边界见[验证记录](https://github.com/Memento1990/codex-task/blob/v0.9.0/docs/releases/v0.9.0-validation.md)。

**首次下载请选择 `CodexFloatboard-0.9.0-windows-x64.zip`**。`Floatboard-update-...zip`是应用内更新专用包，不是完整便携包。

## 功能

- 更多菜单增加版本更新入口，设置页展示当前版本、检查结果、更新内容、下载进度与安装操作。
- 默认后台检查、自动下载，安装前始终明确确认；只重启看板，不结束Codex、Reporter或采集器。
- 固定官方GitHub稳定渠道，Ed25519签名清单、SHA256及大小校验，拒绝降级、错误平台与不可兼容数据更新。
- 独立Rust更新器，版本目录部署、原子指针切换与journal恢复；不覆盖活动EXE。
- 新GUI成功读取首个主窗口snapshot后才确认健康；仍运行但未确认时不强杀，提示正常退出后恢复。
- 看板更新不自动升级Codex连接，兼容旧Reporter证据并显示可选连接组件升级。

## 首次安装与升级

0.8.1不含更新客户端，需完整下载一次0.9.0。运行包根目录CodexFloatboard.exe，保持完整目录结构，不直接启动或固定快捷方式到versions中的程序。

## 安全与边界

生产更新私钥仅在发布机器受保护的仓库外目录；应用内置公钥。便携包仍未做Windows Authenticode代码签名，更新签名不能代替系统签名。系统代理或网络失败不会阻塞看板采集。自动更新不代替Codex信任与重新加载。涉及不可逆数据库迁移的版本暂不支持自动安装。

完整协议与维护流程见[自动更新文档](https://github.com/Memento1990/codex-task/blob/v0.9.0/docs/automatic-updates.md)。
