# v0.10.0 — 贴边浮窗、卡点提醒与任务保留

## 新增与改进
- 详情区可折叠；面板贴近屏幕外侧边缘后可收为头像球，点击恢复原面板。
- 头像球支持沿边拖动、拖离边缘连续恢复；摘要支持始终显示、仅悬停显示、不显示。
- 卡点通知采用醒目的警告样式，保留至解除或手动关闭；普通通知保持低打扰。
- 完成任务按完成片段归档，同会话开始下一项工作后仍可查看旧完成记录。
- 隐藏只有 Hook、没有业务计划的占位任务；移除动态流水，保留计时与去重必要信息。
- 连接状态区分配置、真实观测与版本兼容；开发环境与安装版的数据、控制目录和 WebView 隔离。

## 修复
- 修复托盘恢复与贴边操作之间的 UI 线程/锁等待问题。
- 标题栏按住移动达到阈值后才开始拖动，防止单击粘连；头像拖出后不立即重新收起。
- 更多菜单在外部点击、失焦或 Escape 时关闭，移除重复收起入口。
- 已完成窗口保持与主窗口的置顶关系，避免被置顶主面板遮挡。
- 更新时后台采集器进行正常、安全的版本交接，保留事件邮箱；不结束 Codex 或现有 Hook/MCP 会话。
- 持久化保留空的 legacy history 数组兼容槽，不存储活动流水，兼容旧写入器/回退。

## 更新说明
- v0.9.0 安装版可通过“检查更新”下载签名更新，确认后安装。
- 更新只退出当前 GUI。保留旧版本目录，不删除仍被旧会话占用的文件。
- 数据继续保存在原位置；不会把 DEV 数据合并到正式数据。
- 本版不包含调研报告中建议的跨会话依赖、Claude Code 接入或移动提醒；这些尚未实施。
