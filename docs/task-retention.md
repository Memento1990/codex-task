# 任务展示与留存边界

## 不再展示纯会话占位

Hook 用于会话绑定、运行状态与连接观测；收到 SessionStart、工具事件或 Stop 不等于创建了业务任务。旧实现会把每个 Hook 会话建立为 `unreported` 任务，导致简单问答和没有进度汇报的会话堆积为“未汇报任务”。列表只展示实际结构化汇报或非空计划；仅有运行事件的占位不展示，也不计入任务数量。会话绑定和连接观测仍保留，后续真实汇报可以正常出现。

## 移除动态展示与专属数据

详情只保留清单、卡点、证据。移除动态页及任务对象中的 `history` 动态投影。旧窗口的第四页选择回退到清单。

删除动态展示不等于删除业务计时：进度和计划的最小事件记录仍用于计算任务、步骤、卡点耗时以及防止重复消费。这些不是聊天记录，不读取 Codex 会话索引或原始对话。可写打开旧库时执行一次事务迁移：将持久化 `history` 置为空数组（保留旧写入器兼容槽，API 不再返回该字段），清理非业务 Hook payload，仅保留去重标识；进度/计划事件只保留计时重放所需业务内容。失败整体回滚；只读打开不写库。

## 卡点消息浮窗

存在开放卡点的通知不倒计时关闭；鼠标移出也不会启动自动关闭。用户可以点击关闭或点击通知查看任务。普通通知仍使用设置的停留秒数。通知堆积时不得因为条数或窗口高度限制静默丢弃卡点提醒；关闭通知总开关属于用户明确清除。

## 已完成任务

真实完成必须通过原有验证：清单全完成、有验收证据、没有开放卡点。保留完成快照和计时，不因退出程序而清空，亦不因同一会话接着执行其他任务而丢失。此轮仅准备留存基础，不实现统计看板，不从 Hook 推断完成，不把正常回复结束视为任务完成。

## 开发边界

仅修改源码及隔离开发构建。回归数据使用临时合成 fixture；不清理正式库、不改正式安装、不停止已有 Codex/Reporter 会话。本轮不发布版本。
