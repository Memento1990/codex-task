# 任务留存与计时

业务任务来自 report_progress 完整快照或非空计划。仅有 Hook 的会话占位不展示、不计入任务数量。Hook 用于会话绑定和运行证据，不把 Stop、SessionEnd、断连、休眠或正常回复结束视为任务完成。

详情仅含清单、卡点、证据。非业务 Hook 正文不保存；最小化的业务事件保留用于计时、去重。完成档案按完成 episode 保存；同一会话继续新任务不覆盖之前档案。迁移保留原始任务快照、事件和完成档案的全部版本与来源。

计时只使用留存证据；缺失时间为未知，有缺口的耗时为 partial。重启、休眠断开正在累计的区间，停止在最后可靠心跳或业务证据，不将离线时间补为工时。证据时间是首次记录，不是人工回填的发生时间。

卡点浮窗保留至用户关闭或查看，普通浮窗使用停留设置。外部通知由 Agent 独立执行，见 [通知规则](notifications.md)。

存储故障不返回空列表；已打开 GUI 保留最后内存快照并标失联。新打开且无法连接时显示不可用。删除旧恢复链不影响一致性备份和完整性检查。
